# 安装前先看我

---

## 正文

游戏其实完整支持键盘鼠标，键帽图标素材也全在资源包里，只是界面上默认只画手柄按键  
（Ⓐ 确认 / Ⓑ 取消），键盘玩家只能靠猜。这个 MOD 把缺的那一块补上：

- 你在用键盘鼠标 → 提示图标显示对应的键（↵ 确认 / ← 取消 / J 卸下 / W S 切换角色）
- 你用手柄 → 显示原来的手柄图标
- **热切换**：碰一下手柄就变手柄 UI，碰一下键鼠就变键鼠 UI，不用进设置
- **连键位一起给你配好**：游戏默认那套方向键 + X 攻击实在难用，安装器会顺带把我调好的  
  WASD / J / U I O P 这套写进去，进游戏直接能玩

不修改任何游戏原始文件，提示图标全部在内存里生效；键位则是写进游戏自己的改键存档。  
卸载就是点一下按钮，键位留不留由你选。

### 安装：双击，点一下，完事

1. 下载 `LifeDevoteeKeyboardUI-Setup-v1.1.0.zip`，解压（里面是安装器 + 这份说明）
2. **完全退出游戏**
3. 双击 `LifeDevoteeKeyboardUI-Setup-v1.1.0.exe`，它会自动找到你的游戏目录并做检查
4. 点「安装 MOD」

不用找游戏目录，不需要装 BepInEx，也不需要 .NET 运行时。

> 第一次运行时 Windows 可能弹「已保护你的电脑」（因为个人 MOD 没有数字签名）：  
> 点「更多信息」→「仍要运行」即可。

### 连键位一起装好（默认开启）

安装器里有个默认勾上的「同时写入推荐键位」，装完进游戏就是这套：

| 动作     | 键       |
| ------ | ------- |
| 移动     | W A S D |
| 攻击     | J       |
| 技能 1~4 | U I O P |
| 跳跃     | K       |
| 交互     | F       |
| 处决     | Z       |
| 闪避     | L       |

这是写进游戏自己的改键存档（`%USERPROFILE%\AppData\LocalLow\ArisenForce\LifeDevotee\Rebinds`），  
所以进游戏打开设置页看到的就是这套键，想改随时在游戏里改、改完就是你的。

**不想动键位就把勾去掉**，安装器一个字节都不会碰你的设置。  
如果你之前已经自己改过键，安装器会提示「已有 N 组自定义键位」，覆盖前自动备份。

**想换回自己原来那套键**：打开安装器，点底部独立的「还原键位」按钮即可，  
不用卸载 MOD、也不影响图标功能。这个按钮只在留有备份时才亮着。

### 安装器会检查什么

| 检查项        | 说明                                                     |
| ---------- | ------------------------------------------------------ |
| Steam 客户端  | 从注册表读 Steam 安装位置                                       |
| 游戏 AppID   | 读取 `appmanifest_3279120.acf`，确认是 **Steam 安装的 3279120** |
| 安装完整性      | Steam 记录显示已完整安装                                        |
| 游戏版本       | 比对 `GameAssembly.dll` 的哈希，对应 `2.0.16.20250129`         |
| 已有 BepInEx | 读对方 `Il2CppInterop.Runtime.dll` 的版本，决定装法               |

前两项保证只对**正版 Steam 版本**生效——学习版、绿色版、其他平台版本都过不了校验，  
安装按钮会直接置灰。版本对不上会提示，但允许你确认后继续（游戏小更新通常没事）。

### 和别人已有的 MOD 共存

如果你电脑里已经有 BepInEx（装过别的 MOD），安装器不会一把梭盖掉你的环境：

- **运行时版本一致**（`Il2CppInterop 1.5.3`）→ 只往 `plugins\` 里丢一个 DLL，  
  `core\`、`interop\`、`dotnet\` 一个字节都不碰。你自己的 MOD 完全不受影响，  
  卸载时也只删这一个文件。
- **版本不一致** → 弹窗告诉你对方的版本号，给两个选择：只装插件（可能不生效），  
  或者连运行时一起装。选后者会把被覆盖的文件逐个备份成 `xxx.dll.bak-时间戳`，  
  放到 `LDKUI-Backup\时间戳\`；之后点「卸载 → 彻底卸载」时会问你要不要还原备份，  
  选“是”就把你原来那套 core 文件放回去。
- 装了别的 **BepInEx 5**（没有 `BepInEx.Unity.IL2CPP.dll`）→ 这游戏跑不了 BepInEx 5，  
  安装器直接拒绝并说明原因，不会把环境搞坏。

### 常见问题

**游戏打不开 / 一闪就退**  
杀毒软件把 `winhttp.dll` 当木马了。把游戏目录加进白名单，重新装一次。  
安装器自带的文件都是从开源的 BepInEx 6 来的，报毒是启发式误报。

**装完进游戏没变化**  
先完全退出游戏，再启动一次。安装器刚写完文件时立刻启动，`winhttp.dll` 可能还没落定。

**键鼠 UI 和手柄 UI 自己来回切**  
八成是手柄摇杆漂移了：你手没碰它，它也在持续报坐标，MOD 就误以为你正在用手柄。  
三个办法，挑一个合适的：

1. 键鼠和手柄都插在电脑上 → 去手柄自带的管理软件里把摇杆**死区调大**（Steam 输入的控制器设置里也能调）
2. 只想用键鼠 → 把**手柄拔掉**，全程键鼠，就不可能再切了
3. 只想用手柄 → 全程用手柄就好（不过这样的话，本 MOD 你其实用不上，游戏自己就是手柄 UI）

**装完进游戏，键位还是游戏默认那套**  
多半是 Steam 云同步在你启动游戏时把旧的 `Rebinds` 拉回来了。  
完全退出游戏，再点一次安装（按钮上的勾保持选中）即可；还不行就检查  
`%USERPROFILE%\AppData\LocalLow\ArisenForce\LifeDevotee\Rebinds` 是否存在。  
MOD 本体的图标功能不受影响，键位只是额外附赠的便利。

**提示"检测到其他 BepInEx"**  
你之前装过别的 MOD。安装器会先读对方运行时的版本：一样就只丢插件进去，不动你的环境；  
不一样才问你要不要连运行时一起换，换的时候被覆盖的文件会逐个备份到 `LDKUI-Backup\`。  
不管哪种情况，你原来的东西都能在卸载页一键恢复。

**某个提示的按键还是不对**  
打开 `BepInEx\config\com.arisenforce.lifedevotee.keyboardui.cfg`，  
在 `PromptKeyOverrides` 里按 `节点名=键名` 加一条，比如 `TeamUp=W,TeamDown=S`。  
遇到这种情况欢迎回报，我把它加进默认值。

**Steam 校验文件完整性之后失效**  
校验会删掉 `winhttp.dll` 这类不属于 Steam 的文件，重新点一次安装即可。

**想卸载**  
再打开一次安装器，点「卸载」。可以只删 MOD，也可以连 BepInEx 一起删干净。  
键位会和 MOD 本体分开再问一次「是否保留推荐键位」：

- 选**保留** → 键位一个字节都不动，MOD 删掉后这套键照样能用；以后想换回原来的，  
  随时点「还原键位」
- 选**不保留** → 有安装前备份就还原成你原来那套，没有备份就恢复成游戏默认键位

如果你的环境是被覆盖安装过的，彻底卸载时还会单独问要不要还原那些 core 文件的备份  
（不包含键位，键位按上面那个选择处理）。
